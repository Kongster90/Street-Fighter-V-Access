Street Fighter V Access

A mod that makes Street Fighter V speak through your screen reader. It reads the menus, character and stage select, and much more straight from the game, and speaks through NVDA.

This is a test version. Thank you for trying it. What's new.txt, beside this file, lists what has changed in each version.


What you need

Street Fighter V: Champion Edition on Steam, with the game in English.
Windows 10 or 11.
NVDA running. Without a screen reader it falls back to the Windows voices.
Nothing else: the mod carries everything it needs.


Installing

1. Extract the zip. In File Explorer, press the Applications key on the zip file and choose Extract All.
2. Open the extracted SFV Access folder and run Install SFV Access. If Windows asks whether to run it, choose Run.
3. It puts a Street Fighter V Access shortcut on your desktop, then asks whether the mod should start with the game. Type yes or no and press Enter.
4. If you answer yes and Steam is open, it asks you to press Enter, closes Steam for a moment, and opens it again.

Why Steam has to close: to start the mod with the game, the installer adds it to Street Fighter V's launch options, which live in Steam's own settings file. Steam keeps its settings in memory while it runs and writes them back when it closes, so a change made while Steam is open would be written over. Closing Steam first lets the change stay. Nothing else in Steam is touched, and a download in progress carries on when Steam opens again. Steam only closes when the launch options need changing: when you answer yes, or when you answer no after answering yes on an earlier install, to take them back out. Otherwise, or if Steam is already closed, it is left alone.

That is all. The mod is installed in your programs folder. Once the installer closes, it clears out the extracted folder, leaving only Install SFV Access, Uninstall SFV Access, this file, What's new.txt and VERSION.txt, so the only copy of the mod is the installed one. Both batch files still work from there. You can delete the zip, and the extracted folder too if you like.

Answer yes if you want the mod to start by itself every time you play. It is one less thing to do. On some computers the game then cannot log into its server and shows an error code, and if that happens to you, run the installer again and answer no.

Answer no to start the mod yourself from the desktop shortcut. You can change your mind either way by running the installer again.


Playing

If you answered yes, start Street Fighter V from Steam as usual. The mod starts with the game and closes when the game closes.

If you answered no, start the mod from the Street Fighter V Access shortcut on your desktop. You can do that before or after you start the game. It keeps running until you press F10, so press F10 when you have finished playing.

The first time, it says "Setting up the game's text for the first time", then "The game's text is ready" a few seconds later.

Menus are read as you move through them. Keys that work while the mod runs:

Alt R: say again what is selected, with more detail where there is some.
Alt K: list all the keys.
Alt X: stop speaking.
Alt B: say buttons as Xbox, PlayStation or keyboard keys.
Alt C: say what the buttons on the current screen do.
Alt T: story subtitles off, on (who speaks and what they say), or speaker names only. They are off to start with, since the story voices are in English.
Alt H: during a fight, both fighters' health, V-Trigger and Critical Art.
F5 and Shift F5: make the health beeps louder or quieter, 5 percent at a time. They start at 40 percent, and at 0 they are off.
F6 and Shift F6: the same for the counter hit sound, which plays in the speaker on the side of whoever landed the hit.
F7 and Shift F7: the same for the crossup sound, also on the side of whoever landed it.
Alt M: turn menu reading off or on.
F10: close the mod until the next time you start the game.

These keys only work while the game is in front. Switch to any other program and they do what they normally do there, so to close the mod with F10, be in the game.


What reads so far

Menus and settings, including Controller Settings with each button's action, Button Preview and Keyboard Settings.
Character select, stage select and the VS screen before a fight.
Arcade, Versus and Training, including the result screen and Training's attack data.
Trials, with each combo in words and whether you have cleared it, and Demonstrations.
The Story tutorial's instructions and tips.
The shop, including Fighting Chance and its prizes, notices and missions after logging in, Challenges' Missions, and Extra Battle.
Survival: the supplements and battle items between stages, how each fight went with the health you carry on with, and the result at the end of a run.
Online: the VS screen, who won as each match ends, the result screen and Battle Lounge chat.
Story: Character Story's chapters and each fighter's profile, General Story's chapters and scenes, the scene controls, Costume Settings, and subtitles with Alt T.
Battle Settings, including Random Stage Settings, where each stage says whether it is ticked.
CFN: its menu, the timeline, Pending CFN Friend Requests, Tournaments with their details, and a player's Fighter Profile, each page with its figures on Alt R.
Replays: the controls with each button named, once as a replay begins and on Alt R.
The Message Log, and the Gallery's Good Luck Charms with what each does.
Fights: beeps as either fighter's health drops, and sounds for counter hits and crossups, each in the speaker on the side of whoever it belongs to, in replays and story fights too.

Not yet: a sound for the distance between the fighters.


Keyboard players

If you redo your keyboard mapping in Options, Other Settings, Keyboard Settings, press the key the mod names at each step. The game's own instructions have left and right swapped, and heavy kick and all three punches swapped too, so the mod names each step by what the key really does.


Updating to a newer version

When you get a newer zip, install it the same way over the top. There is no need to uninstall first.

1. If you start the mod yourself, press F10 in the game to close it, then close Street Fighter V.
2. Extract the new zip and run Install SFV Access from it.
3. Answer the question about starting with the game as you like. Your answer can differ from last time.

What's new.txt in the new version lists what has changed. Your own things are kept: your settings, the game's text the mod set up the first time, and the logs. The version you are running is in VERSION.txt in %LOCALAPPDATA%\Programs\SFV Access.


Reporting a problem

Say which screen you were on, what you did, and what you heard, or that nothing was said.

It helps a lot to send the logs from this folder:
%LOCALAPPDATA%\Programs\SFV Access\snapshots
The useful files are spoken-log.txt, scaleform-log.txt, hang-log.txt and crash-log.txt, and console-log.txt if the mod starts with the game. If the mod closes by itself, crash-log.txt is the one that says why. Be aware that they record everything on screen, including your Fighter ID and anything else the game shows.

Mention the version, which is in VERSION.txt in the same folder as this file.


Uninstalling

Run Uninstall SFV Access, either from the extracted folder or from %LOCALAPPDATA%\Programs\SFV Access. Both do the same thing. It removes the desktop shortcut, and takes the mod out of Steam if it was starting with the game, closing Steam for a moment the same way and for the same reason. Then you can delete %LOCALAPPDATA%\Programs\SFV Access, and the extracted folder if you kept it.
